Data Fetching: Caching

Next.js has built-in data caching mechanisms to help improve performance and reduce the number of requests to your data sources.

Automatic Caching with fetch

By default, fetch requests are automatically cached in Next.js. This means that if you make the same request multiple times, the data will only be fetched once. 


async function getData() {
  const res = await fetch("https://api.example.com/data");
  // The result is cached
  return res.json();
}

export default async function Page() {
  const data = await getData();
  return <div>{data.message}</div>;
}

Revalidation Strategies

You can control how data is cached using the revalidate option:

Time-based Revalidation


fetch("https://api.example.com/data", { next: { revalidate: 60 } });

This will cache the data for 60 seconds.

On-demand Revalidation

You can also revalidate data on-demand using the revalidatePath and revalidateTag functions. 


import { revalidatePath } from "next/cache";

export async function POST(request: Request) {
  const path = request.nextUrl.searchParams.get("path") || "/";
  revalidatePath(path);
  return Response.json({ revalidated: true, now: Date.now() });
}

Opting out of Data Caching

You can opt out of caching by setting revalidate to 0 or using the cache: 'no-store' option: 


fetch("https://api.example.com/data", { cache: "no-store" });

This will fetch fresh data on every request.
